## The outcome

Turn a rough idea into a polished, conversion-aware interface. This skill covers landing pages, dashboards, components, emails, and redesigns.

## What you get

A production-ready interface with an intentional hierarchy, responsive behavior, and fewer “AI made this” design tells.

## Quick start

1. Install the ClawHub skill: `frontend-design-skill`
2. Run `/frontend-design`
3. Describe the page, audience, goal, required content, and technical constraints. Ask for a distinct visual direction before implementation.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /frontend-design with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
